## Задача

На вопросы без вариантов агент получает от человека пустоту — надо печатать текст.
Добавить **кнопки частых решений**: одно нажатие вместо набора.

1. `lib/present.js`: `renderRows` для вопроса **без опций** отдаёт ряд быстрых
   ответов (по умолчанию: «Да», «Нет», «Отложить», «Решай сам»), если
   `caps.inlineButtons` и вопрос допускает свободный текст.
2. Нажатие быстрой кнопки приходит в роутинг как `custom` с человекочитаемым
   текстом: «Да» → `custom: "Да"`, «Решай сам» → `custom: "Реши сам, я делегирую"`.
   Модель должна понимать смысл без знания нашей схемы.
3. Набор настраивается в конфиге плагина (`quickReplies: [{label, text}]`), по
   умолчанию — четыре кнопки; пустой список выключает кнопки вовсе.
4. Для вопросов **с вариантами** ничего не меняется: там уже есть варианты и
   «Другой ответ…».
5. Тесты: без опций — ряд быстрых кнопок и `force_reply` не выставляется (иначе
   два способа ввода конфликтуют); нажатие даёт `custom` с нужным текстом;
   конфиг переопределяет набор; пустой конфиг — только текст.

## Критерии готовности

- [ ] вопрос без вариантов приходит с рядом быстрых кнопок;
- [ ] нажатие возвращает `custom` с понятным человеку текстом;
- [ ] набор настраивается, пустой список выключает кнопки;
- [ ] вопросы с вариантами не изменились;
- [ ] `node --test` и `bin/ci.sh --fast` зелёные.
