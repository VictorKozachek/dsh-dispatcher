## Задача

Подготовить релиз **v0.3.2**: после `v0.3.1` в `develop` вошли 13 карточек — почти
все родились из живой эксплуатации (23.11, 20.11).

1. **`dsh-remote/CHANGELOG.md`** — секция `## 0.3.2 — <дата>`, по карточкам
   (сверить с `git log v0.3.1..develop`, формулировки по факту, без «примерно»):
   - `069` имя сессии в шапке: сначала API, затем кэш проекций; фолбэк по `session.id`,
     маска в диагностике, `context.resolve` в журнале;
   - `070` панель «Удалённое управление»: история вопросов за 24 ч (статусы
     доставлен/ошибка/отвечен/не сопоставлен/снят, раскрытие деталей, ротации `.1…5`,
     только чтение);
   - `071` в режиме зеркала ответ в GUI гасит сообщение в мессенджере («✅ Отвечено в GUI»);
   - `072` зеркало больше не предлагает «Другой ответ» и не зовёт печатать текст,
     который будет отброшен: подсказка «ответьте в GUI»;
   - `073` ответ из мессенджера **завершает** tool-call (сессия не висит), поздние и
     повторные ответы отбрасываются как `already-answered`;
   - `074` `/remote approvals` (политика и последнее решение с причиной),
     `allow|deny <tool>`, безопасный дефолт; причина решения в аудите;
   - `075` ранние выходы ответчика журналируются (`question.skipped` с причиной,
     областью и контекстом) — больше не «тишина»;
   - `076` в событиях журнала появился контекст (`sessionId`, `workspace`, `preset`);
   - `077` онбординг подтверждений: один вопрос при `/remote connect`, режимы
     `safe|all|gui-only`, `/remote approvals mode …`, `deny` сильнее `all`;
   - `078` имя сессии доходит до вопросов (`createQuestions` получает контекст целиком);
   - `079` горячая перезагрузка `present`/`i18n` и `/remote reload` (правки текстов и
     шапки без перезапуска приложения);
   - `080` имя сессии в шапке подтверждений (`marksOf` отдаёт весь контекст);
   - `081` журнал действительно пишет контекст (`record` больше не выбрасывает поля),
     фильтр истории по проекту вернулся.
2. **Версия**: `dsh-remote/package.json` → `0.3.2`.
3. **Полный `bin/ci.sh`** (не `--fast`) — прогнать и записать вывод в карточку.
4. Релиз (`bin/release.sh --tag v0.3.2`, тег, `main`) делает **оркестратор** после
   слияния карточки — исполнителю не делать и не пушить.
