## Задача

Сообщения в мессенджере должны читаться с телефона за пару секунд.

1. **Шапка**: компактнее (`▸ проект · task 007 · worker · 18:41`), при наличии
   ветки задачи — короткая ссылка/идентификатор; длинные имена проектов усекаются
   разумно, без «…» посреди слова.
2. **Тело**: код и диффы — в `<pre>` (моноширинно), длинные пути не рвут строку;
   многострочные ответы агента не превращаются в простыню — обрезка по границе
   строки с явным «…ещё N строк».
3. **Подсказки**: «Ответьте текстом» — только если действительно нужен текст;
   «Нажмите кнопку» — если есть варианты; обе сразу не показывать.
4. **Ссылка на задачу**: номер карточки в шапке, при `worktrees/<id>` — путь к
   дереву в подсказке (одна строка, не в теле).
5. Тесты: снапшоты текста для типичных вопросов (короткий, длинный, с кодом,
   с задачей, без задачи), проверка лимита `caps.maxText`, отсутствие двойных
   подсказок, HTML-экранирование.

## Критерии готовности

- [ ] шапка укладывается в одну строку на телефоне (проверить на длинном имени);
- [ ] длинный текст режется по строкам с честным маркером;
- [ ] код/диффы моноширинно и не рвут верстку;
- [ ] подсказка ровно одна и по делу;
- [ ] `node --test` и `bin/ci.sh --fast` зелёные.
