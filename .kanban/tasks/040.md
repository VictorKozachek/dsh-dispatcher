## Задача

Поднять релей локально и довести до него плагин — без хостинга и без телефона.

1. **Сборка и запуск**: `cargo run` из `relay/` (или `deploy/docker-compose.yml`,
   если docker доступен) на `127.0.0.1:8080`; миграции применяются на старте;
   `GET /healthz` → 200. Зафиксировать точные команды в `relay/README.md`.
2. **Smoke**: прогнать `deploy/smoke.sh` против локального релея — healthcheck,
   привязка устройства, публикация вопроса, ответ.
3. **Плагин → релей**: в `dsh-remote` проверить транспорт `relay` на живом
   локальном сервере (без телефона): `/remote connect` → `Relay` →
   `http://127.0.0.1:8080` + токен агента; вопрос из сессии (`ask_user_question`)
   публикуется, а ответ, отправленный через API (`POST /v1/answers`), возвращается
   в сессию. Сценарий описать в `docs/acceptance.md`.
4. **Чего не делать**: не открывать webhook, не настраивать TLS, не выносить
   сервер наружу — это задача 041.

## Критерии готовности

- [ ] `relay/README.md` содержит рабочую последовательность запуска (проверена);
- [ ] `deploy/smoke.sh` проходит на локальном релее (вывод приложен в карточку);
- [ ] вопрос из сессии доходит до релея и ответ возвращается в сессию (лог/скрин в заметках);
- [ ] при недоступном релее вопрос уходит в GUI, а не висит (проверить и записать);
- [ ] `bin/ci.sh --fast` зелёный.
