## Задача

Маркировка вопроса: видно, откуда он — воркспейс, задача, роль, дедлайн.

1. `dsh-remote/lib/present.js`:
   - `resolveContext({ sessionId, ctx })` → `{ workspace, cwd, role, taskId? }`:
     `workspace` — `basename(cwd)` шапки сессии (`ctx.sessions.get(id).header.cwd`),
     `role` — `agentPreset`, `taskId` — номер карточки `.kanban/tasks/*.md` в `cwd`,
     у которой `owner` совпадает с `sessionId` (только чтение; ошибки/отсутствие
     каталога — тихо, без `taskId`);
   - `renderHeader(ctx)` → `▸ dsh-dispatcher · task 007 · worker · 17:41 · до 18:11`
     (порядок и разделители — как в `docs/CONCEPT.md` §5.2; без задачи — без
     сегмента; длинный воркспейс/путь — усечение до 32 символов);
   - `renderBody(q, caps)` → текст сообщения: шапка, пустая строка, тело вопроса,
     при `multiSelect` — подсказка «можно несколько»; усечение под `caps.maxText`
     с честным маркером «…обрезано»;
   - `renderRows(q, caps)` → ряды кнопок: варианты по одной в ряд, «Другой ответ…»
     последним, при `options.length > caps.maxOptions-1` — «Показать ещё»;
   - `renderClock(now, expiresAt)` → `17:41 · до 18:11`, локальная зона машины.
2. Тесты `test/present.spec.js`: без задачи; с задачей; воркспейс-путь длинный;
   нет каталога `.kanban` → нет `taskId` и нет исключения; 12 вариантов → «Показать ещё»;
   усечение под лимит; эмодзи в тексте не ломается.

## Критерии готовности

- [ ] в шапке есть воркспейс и время; задача и роль — когда они известны;
- [ ] `resolveContext` не падает при отсутствии `.kanban` и при чужой сессии;
- [ ] карточки `.kanban` только читаются (тест: файл не изменён);
- [ ] все строки укладываются в `caps.maxText` (с маркером усечения);
- [ ] нет записи в `worktrees/` других задач и в основной чекаут;
- [ ] `node --test dsh-remote/test` — зелёный.

## Заметки

- Путь к шапке сессии: `packages/core/session/src/types.ts` (`cwd`, `agentPreset`).
- Формат карточки: `.kanban/tasks/README.md` (в этом проекте) — `owner` это `$DSH_SESSION_ID`.
- Маркировка — только отображение: ничего в доску не пишем и статусов не двигаем.

- Концепция — `docs/CONCEPT.md` (разделы 3–8), спека — `.kanban/specs/001.md`.
- Каталог задачи — `worktrees/<id>` (ветка `task/<id>`). Сессия роли живёт в корне
  проекта, поэтому **работать только внутри `worktrees/<id>`**: `cd worktrees/<id>`,
  дальше всё относительно него; в корне и в чужих `worktrees/*` не писать.
- Общие файлы не трогать: `AGENTS.md`, `.kanban/` (кроме своей карточки), `bin/task-*.sh`.
- Профиль DSH (`~/.dsh/profiles`) в этой задаче не правится — установку делает человек/оркестратор.
- Язык: JS (ESM), только `node:` builtins; тесты — `node --test` (если `node` не в PATH — `bin/node.sh`).
- Все git-команды и `bin/task-move.sh` — из каталога задачи (`cd worktrees/006`);
  основную ветку и карточки других задач не трогать.
- Сдача: `cd worktrees/006 && bin/task-move.sh 006 in-review --role worker --tokens auto --note "..."`.
