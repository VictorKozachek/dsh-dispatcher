## Задача

Панель показывает вопросы, но не показывает **состояние работы**: что в работе,
что ждёт человека, сколько сожжено токенов.

1. `lib/panel.js`: добавить блок «доска» — по каждому воркспейсу: количество
   карточек в `in-progress`, `in-review`, `testing`, `ready`, `blocked`;
   карточки, висящие у текущей роли дольше `staleMinutes` (по умолчанию 30) —
   отдельным списком с временем.
2. Блок «расход»: токены по задачам из фронт-маттера карточек (`tokens`,
   `tokens_<роль>`), сумма за сегодня/неделю — из метрик (031), без новых файлов.
3. Данные — только чтение: панель ничего не двигает и не пишет в `.kanban`.
4. Тесты: сводка по статусам считается верно (фикстуры карточек), залипшие
   карточки видны, сумма токенов сходится, при отсутствии доски — «нет данных»,
   а не падение.

## Критерии готовности

- [ ] панель показывает статусы доски по воркспейсу;
- [ ] видно карточки, залипшие у роли дольше N минут;
- [ ] расход токенов по задачам и сумма за период;
- [ ] `.kanban` только читается (тест: файлы не изменены);
- [ ] `node --test` и `bin/ci.sh --fast` зелёные.
