## Задача

Достать локальный релей с телефона — без VPS, через туннель.

1. **Туннель**: поднять `cloudflared tunnel --url http://127.0.0.1:8080` (или
   `ngrok http 8080`, или Tailscale) и получить HTTPS-адрес.
2. **Привязка клиента**: в приложении (Android или iOS) ввести адрес туннеля и
   pairing-код; получить вопрос из сессии на телефон и ответить.
3. **Оговорки**: адрес живёт, пока жив туннель; описать, как перезапустить и
   что делать при смене адреса (перепривязка). Для Android/iOS явно указать, что
   cleartext-HTTP допустим только для `127.0.0.1`/LAN, а туннель даёт HTTPS.
4. **Документация**: раздел в `docs/user-guide.md` — «релей на ноутбуке + телефон»,
   с командами и ожидаемым результатом.

## Критерии готовности

- [ ] получен HTTPS-адрес туннеля, клиент привязывается к нему;
- [x] клиентский путь проверен без физического устройства: **RelayKit через HTTPS-туннель** (тот же код, что в iOS-приложении) — привязка по коду, вопрос, ответ, чтение ответа агентом;
- [ ] (проверка владельца, не блокирует карточку) вопрос на физическом телефоне — выполняется человеком по `docs/user-guide.md §10`;
- [ ] описано, что делать при смене адреса туннеля;
- [ ] `docs/user-guide.md` содержит рабочий сценарий;
- [ ] `bin/ci.sh --fast` зелёный.
