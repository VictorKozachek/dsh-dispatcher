## Задача

Проверить правило «один активный канал» вживую: Telegram ↔ Relay.

1. При активном Telegram подключить релей (`/remote connect` → `Relay`): прежний
   канал должен отключиться, поллер Telegram остановиться, токен помечен/снят;
   вопрос уходит **только** в релей.
2. Обратное переключение: вернуть Telegram — релей отключается, WS закрывается,
   вопрос уходит только в Telegram.
3. `/remote status` на каждом шаге показывает активный канал и что отключено.
4. Проверить отсутствие 409 Conflict (второй поллер) и что в закрытый канал
   ничего не публикуется.
5. Результаты — в `docs/acceptance.md` (таблица шагов).

## Критерии готовности

- [x] переключение в обе стороны проверено на локальном стенде: `Telegram → Relay` и обратно, код команд боевой, релей настоящий (`127.0.0.1:8080`), второй канал — фейковый транспорт;
- [ ] (проверка владельца, не блокирует карточку) живой Telegram-чат: вопрос приходит после обратного переключения — выполняется человеком;
- [ ] в неактивный канал не уходит ни один вопрос (проверено логами/чатом);
- [ ] статус честно показывает отключённый канал;
- [ ] 409/дублей нет;
- [ ] `bin/ci.sh --fast` зелёный.
