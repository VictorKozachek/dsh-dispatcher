## Задача

Self-host релея: поднять на своём VPS или домашнем сервере одной командой.

1. `deploy/docker-compose.yml`: релей (017), Caddy с автоматическим TLS,
   том для БД, restart policy, healthcheck.
2. Конфиг через переменные окружения (`.env.example`), валидация на старте,
   понятные сообщения об ошибке при отсутствии обязательных переменных.
3. `deploy/README.md`: требование к домену, как выпускается сертификат, как
   привязать первое устройство, как обновлять, как бэкапить и восстанавливать
   состояние (SQLite + ключи), как отзывать устройство.
4. Скрипт `deploy/backup.sh` (run-cron-friendly) и `deploy/restore.sh` с проверкой
   целостности; smoke-тест `deploy/smoke.sh` — healthcheck + привязка + вопрос/ответ.
5. Тесты: `bash -n` для скриптов; smoke-тест против локально поднятого релея
   (или, если Docker недоступен, — зафиксировать в заметке и описать ручной шаг).

## Критерии готовности

- [ ] `docker compose up` поднимает релей и Caddy, `/healthz` отвечает;
- [ ] `.env.example` документирован, секреты не в git;
- [ ] backup/restore проверены (поднять, сохранить, восстановить, ответить на вопрос);
- [ ] README описывает полный путь «VPS → домен → TLS → привязка → вопрос»;
- [ ] скрипты проходят `bash -n`.
