## Задача

Живой скриншот 23.11 (подтверждение действия из проекта `infra`):

```
▸ infra · task AIF-160 · Сессия менеджера направления… · 17:17 …
```

Имя сессии обрезано по общему `HEADER_LIMIT` (64), и понять, **какое направление**,
невозможно. То же будет с любым длинным именем (`Сессия менеджера направления
«Инфраструктура и надёжность»`) и в вопросах, и в подтверждениях.

Причина: `renderHeader` собирает **одну строку** `проект · task · роль/имя · время ·
до 18:41` и усекает её целиком, поэтому длинное имя съедает всё остальное (включая
время и дедлайн) и теряет смысл первым.

## Требования

1. **Имя сессии — отдельной строкой** под шапкой (или второй строкой шапки):
   - шапка остаётся компактной: `▸ проект · task ID · время · до HH:MM`;
   - имя печатается целиком, с переносом по словам; если всё равно не влезает —
     усечение **по границе слова** и **сохраняя начало** (не «…направления»);
   - для вопросов и для подтверждений одинаково (`renderBody` общий).
2. Предел на имя (например, 2 строки × 40 символов) — считать от `caps.maxText`,
   чтобы не съесть тело вопроса: тело всё равно имеет приоритет.
3. Если имени нет — поведение прежнее (пресет в шапке, как сейчас).
4. Не ломать: `#047` (компактная шапка, `HEADER_LIMIT`), `#068/#078/#080` (имя
   сессии), `#044` (подсказки под вопросом), усечение тела.
5. Тесты: длинное имя (60+ символов) видно целиком или усечено по слову с понятным
   началом, в обеих строках; время и дедлайн не теряются; короткое имя — как
   раньше; тело вопроса не вытесняется именем (лимит `caps.maxText` соблюдён);
   подтверждение рендерится так же, как вопрос.

## Критерии готовности

- [ ] длинное имя сессии не съедает время/дедлайн и не обрезается посреди слова (тест);
- [ ] имя видно в MAX/Telegram как отдельная строка под шапкой (снапшот-тест);
- [ ] без имени — прежнее поведение (регресс);
- [ ] предел `caps.maxText` соблюдён, тело вопроса не вытеснено (тест);
- [ ] `node --test` и `bin/ci.sh --fast` зелёные;
- [ ] живая проверка: подтверждение из проекта с длинным именем сессии читается.
