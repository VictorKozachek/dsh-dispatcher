  1) Воспроизведение минимальное (на этой машине, Swift 6.4/Xcode 27.2):

     То же для `https://` (допустимы только ws/wss).
  2) Путь в коде: `RelayClient.socketEvents` (Sources/RelayKit/RelayClient.swift:154–159) делает
     `var request = URLRequest(url: baseURL.appendingPathComponent("v1/events"))` и
     `session.webSocketTask(with: request)` — без замены схемы. `AppModel.activate()` (Sources/RelayApp/AppModel.swift:95–105) запускает `client.events()` сразу после привязки/восстановления, а `AppModel.pair` принимает только `http`/`https` (там же, строка 61) — ввести `ws://` пользователь не может.
