## Задача

Интерфейс и сообщения наполовину русские, команды — английские. Привести к двум
языкам: **RU** и **EN**, с выбором без перезапуска.

1. `lib/i18n.js`: словари `ru`/`en` для текстов сообщений (`present.js`),
   ответов команд (`/remote …`) и панели; функция `t(key, params)` с подстановкой.
2. Выбор языка: явная настройка (`/remote lang ru|en`) → локаль DSH → `ru` по
   умолчанию. Язык хранится в состоянии, применяется к следующим сообщениям.
3. Команды и ключи API не переводятся: `connect/on/off/status/...`, имена полей,
   `callback_data` — латиницей всегда.
4. Тесты: оба словаря покрывают одни и те же ключи (тест на полноту), форматирование
   с подстановкой, `/remote lang` меняет язык, неизвестный ключ не ломает вывод.
