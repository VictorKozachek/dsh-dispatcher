## Задача

Подготовить релиз **v0.3.3**: после `v0.3.2` в `develop` вошла спека 011
«Надёжность мессенджеров» (живые наблюдения 23–24.11).

1. **`dsh-remote/CHANGELOG.md`** — секция `## 0.3.3 — <дата>`, по карточкам
   (сверить с `git log v0.3.2..develop`, формулировки по факту):
   - `#083` длинное имя сессии больше не обрезается: шапка компактная
     (`проект · task · время · до`), имя — отдельной строкой с переносом по словам;
   - `#084` снятие вопроса (TTL/аборт/рестарт) **правит сообщение одной операцией**:
     текст «⌛ вопрос снят …» + пустые кнопки (Telegram `inline_keyboard: []`,
     MAX `attachments: []`); предварительная пометка «ждёт ответа» убрана;
     журнал `question.expired {ttl|aborted|restart}` и `question.closeFailed`;
     повтор с backoff на 429; `recover` чистит `pending`/`questions`;
   - `#085` клик/текст по закрытому вопросу → видимая подсказка («уже снят» /
     «уже отвечен»), без спама; журнал `answer.rejected {unknown|expired|already-answered}`;
   - `#086` сторож канала: N минут тишины или серия ошибок → перезапуск транспорта
     (backoff 1/2/3 с), после 3 неудач `channel.failed`; `status` показывает
     «последний апдейт N мин назад», перезапуски, последнюю ошибку; сторож не
     мешает отправке (учитывает in-flight доставки);
   - `#087` напоминания и TTL-пометки — **правкой** сообщения (кнопки сохраняются),
     при невозможности одно новое с пометкой «(обновление)»; журнал
     `question.reminder {via: edit|new|dropped}`.
2. **Версия**: `dsh-remote/package.json` → `0.3.3`.
3. **Полный `bin/ci.sh`** (не `--fast`) — прогнать, вывод записать в карточку.
4. Релиз (`bin/release.sh --tag v0.3.3`, тег, `main`, пуш) делает **оркестратор**
