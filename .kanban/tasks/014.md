## Задача

Короткие уведомления о событиях доски в тот же канал — без подмены карточки.

1. `dsh-remote/lib/notify.js`: чтение `.kanban/tasks/*.md` (read-only) по воркспейсу,
   отслеживание переходов: карточка ушла в `ready` («можно вливать»), в `blocked`
   («нужен человек»), в `todo` стало меньше `minTodo` («пора выдать»).
2. Отправка — отдельный тип сообщения (`notify`), без кнопок ответа; дедуп через
   `store` (ключ `id:status:updated`), пауза между сообщениями, тихие часы
   (например, не отправлять 23:00–08:00 — конфиг).
3. Состояние доски читается по путям из `store`/конфига (список воркспейсов),
   карточки не меняются ни при каких условиях — это важно: статусы двигает только
   `bin/task-move.sh`.
4. Тесты: переход в `ready` → одно уведомление; повторное чтение → не дублирует;
   `blocked` → уведомление с причиной из `note`; запись в `.kanban` не происходит
   (проверка по mtime/hash).
