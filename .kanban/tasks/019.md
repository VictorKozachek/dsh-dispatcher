## Задача

Android-приложение MVP: привязка, список вопросов, ответ.

1. `apps/android/` — Kotlin + Jetpack Compose, минимальная структура проекта
   (Gradle), один модуль `app`.
2. Экраны: привязка (URL релея + pairing-код), список открытых вопросов (воркспейс,
   задача, дедлайн), экран вопроса (варианты кнопками, свободный текст), «закрытые».
3. Транспорт: WebSocket к релею (016) с переподключением, оффлайн-очередь ответов
   (`WorkManager` или своя очередь), отправка ответа идемпотентно.
4. Push: FCM — опционально; без аккаунта FCM приложение живёт на WS в foreground
   и на периодической проверке в background (явно описать ограничение в README).
5. Тесты: unit-тесты ViewModel/репозитория с фейковым транспортом; сборка
   (`./gradlew test`) — если Android SDK недоступен, зафиксировать в заметке.
