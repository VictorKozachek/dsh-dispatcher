## Задача

`/remote connect` → MAX не проходит на первом же запросе: `GET /me` к
`platform-api2.max.ru` падает с TLS-ошибкой, потому что сертификат хоста выписан
**Russian Trusted Sub CA (Минцифры)**, а его корня нет в trust store macOS/Node:

```
$ node -e "await fetch('https://platform-api2.max.ru/me')"
UNABLE_TO_GET_ISSUER_CERT_LOCALLY

$ node -e "await fetch('https://platform-api.max.ru/me')"
401   # хост доступен, TLS в порядке, просто нет токена
```

При этом пользователь видит только «MAX не принял токен: fetch failed» и не
понимает, что дело не в токене.

## Требования

1. **Фолбэк хоста**: в `lib/transport/max.js` и в MAX-ветке `connect` при ошибке
   TLS/сети (`UNABLE_TO_GET_ISSUER_CERT_LOCALLY`, `fetch failed`, `ERR_TLS_*`)
   повторять запрос на `platform-api.max.ru` (публичный CA, тот же API) и
   запоминать рабочий хост в состоянии транспорта (для `doctor`).
2. **Конфигурируемая база**: `config.maxApiBase` (строка) — если задана, фолбэка
   нет, используется ровно она; поддержать и `MAX_API_BASE` из окружения.
3. **Понятная ошибка**: если обе базы недоступны по TLS — сообщение вида
   «TLS к MAX не проходит: сертификат platform-api2 выписан Russian Trusted CA.
   Варианты: (а) оставить фолбэк на platform-api.max.ru; (б) задать
   NODE_EXTRA_CA_CERTS=/путь/к/russian_trusted_root_ca.pem», без «fetch failed».
4. **Документация**: `docs/user-guide.md` и `dsh-remote/README.md` — раздел про
   этот TLS-случай и почему `platform-api.max.ru` используется как фолбэк.
5. **Тесты** (фейковый `fetch`): api2 бросает TLS-ошибку → запрос уходит на api и
   успешен; заданный `maxApiBase` отключает фолбэк; обе базы падают → текст с
   вариантами; `doctor` показывает активный хост.

## Критерии готовности

- [ ] при TLS-ошибке api2 запрос автоматически повторяется на `platform-api.max.ru`;
- [ ] `maxApiBase`/`MAX_API_BASE` полностью переопределяют хост;
- [ ] сообщение об ошибке объясняет причину и два способа решения;
- [ ] тесты на три сценария (фолбэк, override, обе базы недоступны);
- [ ] `node --test` и `bin/ci.sh --fast` зелёные.
