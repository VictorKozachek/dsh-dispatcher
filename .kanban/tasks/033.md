## Задача

Журналы не должны съедать диск.

1. `lib/audit.js`/`log.jsonl`: ротация по размеру (`maxBytes`, по умолчанию 5 МБ)
   и по количеству файлов (`keep`, по умолчанию 5), атомарное переименование,
   без потери последней записи.
2. `/remote vacuum` — принудительная очистка старых файлов; `--dry-run`.
3. `state.json` — ограничение «recent» и очереди (`maxPending`), чтобы файл не рос
   бесконечно; отбрасывание с записью в журнал.
4. Права файлов: журналы `chmod 600` (там бывают id пользователей).
5. Тесты на фейковой ФС (или tmp-каталоге): ротация при превышении, `keep`
   соблюдается, vacuum с `--dry-run` ничего не удаляет, права выставлены.

## Критерии готовности

- [ ] ротация не теряет записей и не оставляет битых файлов;
- [ ] `--dry-run` безопасен;
- [ ] размер состояния ограничен;
- [ ] права `600` на журналы;
- [ ] `node --test dsh-remote/test` зелёный.
