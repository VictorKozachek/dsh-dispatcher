## Задача

Обновление плагина без сюрпризов.

1. `dsh-remote/package.json`: `version`, и `bin/install-remote.sh --update`:
   сравнение установленной версии (из профиля) с текущей, вывод плана,
   `--dry-run` по умолчанию безопасен, откат (`--rollback <version>`) при
   наличии предыдущей версии в кэше.
2. `CHANGELOG.md` в `dsh-remote/` — формат «версия — дата — что изменилось».
3. Проверка совместимости: перед установкой — `node --check`/импорт модуля и
   проверка `schemaVersion` состояния (032); несовместимость → отказ с инструкцией.
4. Тесты: `bash -n`; `--update --dry-run` печатает версии и ничего не меняет;
   откат без кэша честно отказывает.

## Критерии готовности

- [ ] `--update` идемпотентен и не ломает установку, если версия та же;
- [ ] `CHANGELOG.md` ведётся с первой версии;
- [ ] несовместимое состояние блокирует установку с понятным текстом;
- [ ] `bash -n` и `node --test dsh-remote/test` зелёные.
