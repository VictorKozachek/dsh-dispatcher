## Задача

Свободный ответ и маршрутизация, когда вопросов и сессий несколько.

1. `dsh-remote/lib/routing.js`:
   - `routeIncoming({ transport, answer, store, log })` → `{ question, answer } | 'ambiguous' | 'ignored'`:
     по `callback_data` (`shortId` + option id) — точное попадание;
     по `reply_to_message_id` — вопрос того сообщения;
     если открыт ровно один вопрос с `allowFreeText` — принимаем свободный текст;
     если несколько — возвращаем `ambiguous` и просим реплай/кнопку;
   - нормализация текста: trim, лимит длины (по `caps.maxText`), запрет пустого ответа,
     многострочный текст допустим;
   - привязка «Другой ответ…»: нажатие переводит вопрос в режим ожидания текста
     (`awaitingText`), текст засчитывается один раз;
   - `describeOpen(questions)` — человекочитаемый список открытых вопросов для
     сообщения «уточните, к какому вопросу» (номер, воркспейс, задача).
2. Тесты `test/routing.spec.js`: кнопка → нужный вопрос; reply → нужный вопрос;
   текст при одном открытом free-text; текст при двух → `ambiguous`;
   «Другой ответ…» → следующий текст засчитан; повторный ответ игнорируется;
   текст от чужого пользователя (allowlist, из 004) не доходит до роутинга.

## Критерии готовности

- [ ] ответ всегда попадает в свой вопрос или отвергается с понятным сообщением;
- [ ] `ambiguous` не теряет ответ: человек получает подсказку, вопрос остаётся открытым;
- [ ] «Другой ответ…» работает, повторный текст не перетирает первый ответ;
- [ ] многострочный и длинный текст корректно усечён/принят;
- [ ] `node --test dsh-remote/test` — зелёный.
