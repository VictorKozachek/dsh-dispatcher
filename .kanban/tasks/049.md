## Задача

Перевести **вывод команд** `/remote` на словари (продолжение 046, вынесено
оркестратором как отдельный объём).

1. `lib/commands.js`: 226 русских строк — `connect` / `connectRelay` / `connectMax`,
   `doctor` (все проверки и подсказки `action`), `audit`, `channel`, `stats`,
   `vacuum`, ошибки и подписи статусов.
2. Все строки — через `t(key, params)` из `lib/i18n.js`; ключи сгруппировать по
   командам (`commands.connect.*`, `commands.doctor.*`, …), чтобы словарь читался.
3. Ничего не переводить из: имён команд, полей состояния, `callback_data`, текстов
   ошибок платформы (Telegram/MAX API приходят готовыми).
4. Тест полноты словарей должен остаться зелёным (обе локали одинаково покрывают ключи);
   добавить тест «в `commands.js` нет русских литералов вне словаря» — простым
   поиском кириллицы в строковых литералах (или явным allowlist для исключений).
5. Проверить на живом `/remote status` и `/remote doctor` в двух языках — вывод
   читается, ключи не «просвечивают» (`undefined`, `${…}`).

## Критерии готовности

- [ ] в `commands.js` нет пользовательских русских строк вне словаря (тест);
- [ ] `/remote status`, `doctor`, `audit`, `channel` читаются на RU и EN;
- [ ] ключи не «просвечивают»: нет `undefined` и сырых `${…}` в выводе;
- [ ] тест полноты словарей зелёный;
- [ ] `node --test` и `bin/ci.sh --fast` зелёные.
