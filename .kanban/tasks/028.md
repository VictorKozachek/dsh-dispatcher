## Задача

Гибрид и fallback для подтверждений.

1. `approvals.onTimeout`/гибрид: не ответили `hybridWaitMs` — запрос уходит в GUI
   (`next()`); поздний ответ из канала НЕ переигрывает решение, а пишется в аудит
   как «поздний».
2. Недоступный транспорт → сразу GUI (как у вопросов); сообщение в канале
   помечается «устарело».
3. Конфиг: `approvals.hybrid: true|false` (по умолчанию `false`), `hybridWaitMs`.
4. Тесты на фейковых часах: таймер → `next()` один раз; ответ до таймера → GUI не
   зовётся; ответ после → аудит и сообщение «устарело»; отключённый гибрид — как в 024.

## Критерии готовности

- [ ] `next()` вызывается не более одного раза;
- [ ] поздний ответ не меняет исход и виден в аудите;
- [ ] выключенный гибрид не меняет поведение 024;
- [ ] `node --test dsh-remote/test` зелёный.
