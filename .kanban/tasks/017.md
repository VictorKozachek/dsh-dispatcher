## Задача

Релей на Rust по протоколу 016.

1. `relay/` — cargo-проект (axum + tokio): эндпоинты из 016, хранение (SQLite через
   `sqlx`, миграции в `relay/migrations`), WebSocket для онлайн-устройств,
   long-poll fallback для оффлайна, очередь доставки с TTL и повторами.
2. Привязка: код pairing (TTL 10 мин), allowlist устройств, отзыв устройства с
   закрытием его сессий.
3. Наблюдаемость: `GET /healthz`, структурные логи (без тел вопросов), метрики
   минимум счётчиками.
4. Тесты: интеграционные на tokio (поднять сервер на случайном порту, прогнать
   сценарий привязки, вопроса, ответа, TTL), плюс юнит-тесты хранилища.
5. Если `cargo` недоступен в окружении — зафиксировать это в заметке карточки
   и оставить проверяемые тесты, которые сможет прогнать тот, у кого тулчейн есть.

## Критерии готовности

- [ ] `cargo test` (или зафиксированное отсутствие тулчейна + инструкция);
- [ ] сценарий «привязка → вопрос → ответ → TTL» покрыт интеграционным тестом;
- [ ] сервер не падает на битом конверте и на неизвестной версии;
- [ ] логи не содержат тел вопросов и токенов;
- [ ] `relay/README.md` — запуск локально одной командой.
