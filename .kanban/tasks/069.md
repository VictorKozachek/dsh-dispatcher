## Задача

После `#068` (имя сессии в шапке) **вживую имя не появляется**: в MAX шапка
по-прежнему `▸ dsh-dispatcher · standard · …`, хотя в кэше проекций у этой сессии
`title.val = "Оркестратор"`.

Проверено 18.11:

- функция в изоляции работает: `sessionTitleFromProjection('session-8aac9774-…')`
  → `"Оркестратор"`, а `resolveContext` + `renderBody` дают
  `▸ dsh-dispatcher · Оркестратор · 18:28 · до 18:58`;
- файл существует: `~/.dsh/storages/session_projcache/sessions/session-8aac9774-….json`;
- в живом плагине шапка показывает `standard` (то есть `role` из
  `header.agentPreset` найден, а `sessionTitle` — `null`).

**Гипотеза:** `request.agent.id` — это id **агента**, а не сессии; `sessions.get(id)`
его принимает и отдаёт заголовок (оттуда `agentPreset`), но имя файла проекции
строится из id агента, и файл не находится. Либо у возвращаемого объекта есть
своё поле `id` (id сессии), которое надо использовать для поиска проекции.

## Требования

1. **Диагностика (обязательно):** при резолве контекста писать в журнал
   (`remoteJournal`, событие `context.resolve`) безопасные поля: `sessionId`
   (первые 8 символов + маска), `session.id` из ответа `sessions.get` (если есть),
   `foundTitle: true|false`, `preset`. Никаких полных id и имён — только факты.
2. **Фолбэк по id из объекта сессии:** если `session?.id`/`session?.sessionId`
   задан и отличается от `request.agent.id` — искать проекцию по нему (сначала по
   id агента, затем по id сессии).
3. **Не ломать 068**: если имени нет ни там, ни там — `agentPreset` (как сейчас).
4. Тесты: `session.id` отличается от переданного — имя находится по второму id;
   оба отсутствуют — пресет; журнал `context.resolve` пишет `foundTitle`.
5. Проверить вживую: после правки шапка в MAX содержит имя сессии.

## Критерии готовности
