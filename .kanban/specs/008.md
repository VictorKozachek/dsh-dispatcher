# Спека 008: Полировка UX и удобство

Статус: нарезана (карточки 044–047).
Основание: после живой приёмки 2026-11-11 каналы работают, но ежедневное
использование упирается в мелочи: кнопки только те, что дал агент, статуса по
задачам и токенам нет, интерфейс наполовину русский, сообщения длинные.

## Зачем

Системой пользуются с телефона, на ходу. Значит важны не возможности, а скорость:
меньше чтения, меньше нажатий, понятный статус. Всё это делается без внешних
шлюзов и без новых разрешений — только код и тексты.

## Требования

1. **Быстрые ответы** — частые решения одной кнопкой: «Да», «Нет», «Отложить»,
   «Сделай как считаешь лучше» — для вопросов, где агент не дал вариантов. Набор
   настраивается; клик уходит как `custom`, чтобы модель поняла смысл.
2. **Статус задач в панели** — сколько карточек в каждой колонке, какие ждут
   человека дольше N минут, расход токенов по задачам (данные уже есть в
   карточках и метриках).
3. **Локализация RU/EN** — тексты сообщений, команды и панель на двух языках;
   выбор — по локали DSH или явной настройке, не по языку модели.
4. **Полировка сообщений** — компактная шапка, явная ссылка на задачу (номер +
   ветка), аккуратное усечение кода/диффа, подсказка «как ответить» только там,
   где она нужна.
5. Ничего из этого не ломает правило «один активный канал» (038) и не требует
   перезапуска после подключения (уже сделано).

## Вне скоупа

- новые каналы и approvals;
- мобильные приложения (они уже есть, UI — отдельная история);
- темы оформления.
