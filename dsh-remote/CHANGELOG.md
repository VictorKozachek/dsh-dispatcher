# Changelog

Формат: версия — дата — что изменилось. Версия плагина — `dsh-remote/package.json`.

## 0.3.0 — 2026-11-11

- **Один активный канал (038, 042).** Подключение нового канала отключает прежний;
  открытые вопросы старого канала снимаются, ответ и закрытие идут в канал, где
  вопрос был доставлен; `status` показывает секрет и состояние активного канала
  (Telegram / MAX / Relay). Переключение проверено на локальном стенде с реальным
  relay и RelayKit через HTTPS-туннель; живой Telegram-чат снят по решению
  оркестратора — это проверка владельца, а не автотест.
- **MAX через `/remote connect` (039).** Токен, pairing-код, привязка и запуск
  канала без перезапуска профиля; pairing через long polling.
- **Локальный релей (040) и HTTPS-туннель (041).** Запуск `dsh-relay` на
  `127.0.0.1:8080`, миграции на старте, smoke-тест, плагин → релей без телефона;
  внешний доступ проверен через SSH-туннель `localhost.run` клиентом RelayKit по
  HTTPS (cloudflared quick tunnel в этой сети давал 502/530; Tailscale —
  документированный вариант, вживую не проверялся). UI-приложение на телефоне не
  проверялось — это проверка владельца.
- **Исправления живой приёмки.** Сервисы берутся через `ctx.get` (cordis запрещает
  прямой доступ без `inject`); ленивый поиск секретов, когда `ctx.credentials`
  монтируется позже плагина; канал поднимается повторами после старта; поле ввода
  (`force_reply`) для вопросов без вариантов; тесты изолированы от живого
  состояния (`DSH_HOME`).
- **Эксплуатация (036).** Soak-тест на 1000 вопросов, RUNBOOK с SLO и покрытием
  `doctor`-fail; `log.jsonl` ротируется по единому пределу 5 МиБ (`rotate.js`).

## 0.2.0 — 2026-11-03

- Установщик: `--update` (сравнение версий из профиля и пакета), `--rollback <version>`
  из кэша предыдущих версий, проверка совместимости (`node --check` + schemaVersion
  состояния 032) перед установкой.
- Аудит решений, политика подтверждений (allowlist/denyRemote/TTL), очередь и
  роутинг подтверждений, гибрид с GUI, метрики `/remote stats`, doctor 2.0,
  ротация журналов и `/remote vacuum`.
- Состояние: схема v2 и миграция v1 → v2 с бэкапом.

## 0.1.0 — 2026-11-02

- Первая версия: вопросы и подтверждения в Telegram/MAX, relay-транспорт,
  привязка через `/remote connect`, установщик в профиль.
